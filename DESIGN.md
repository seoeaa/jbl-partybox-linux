# Дизайн нативного клиента

Согласованное направление: современное обычное Linux-окно на Python. После пользовательского отклонения Tk используется GTK4/libadwaita, режим Operate.

- Системная светлая/тёмная Adwaita, стандартный GNOME accent, системная типографика.
- Adw.HeaderBar; прокручиваемые группы: состояние BLE, звук Linux, свет, громкость/бас и диагностика.
- Отдельно показывать control connection и audio routing; последний изменяется только кнопкой.
- ActionRow/ComboRow с контекстной кнопкой Apply рядом с контролом. Между аудиоблоком и кнопкой проверки отступ12px.
- Минимальный размер640×600, обычный760×760. Не прятать функции за обрезанием: вертикальная прокрутка и keyboard focus.
- ВнешниеI/O только worker; программное обновление переключателей под guard, никогда не инициирует запись.
- Иконка: собственная тёмная колонка с оранжевыми кольцами, без официального JBL logo. App/icon ID org.partybox.Linux710.
