# JBL PartyBox 710 для Linux
<!-- impeccable:product-schema 1 -->

## Platform
Linux desktop (GTK4/libadwaita).

## Stack
Пользователь подтвердил обычное Python-окно без браузера и попросил современный интерфейс. GTK4/libadwaita через системный PyGObject; BLE и аудио backend на стандартной библиотеке Python.

## Users
Владелец JBL PartyBox 710, управляющий своей колонкой с Ubuntu 24.04.

## Product Purpose
Подсветка, громкость и Bass Boost без Android-приложения; явный выбор вывода системного звука Linux. Прочитать реальное состояние и подтверждать изменения чтением.

## Operating Context
Колонка используется рядом с компьютером Ubuntu. BLE и A2DP рассматриваются независимо: подключение управления не означает выбор аудиовыхода. Не разрывать A2DP; не отправлять команды при инициализации элементов управления.

## Capabilities and Constraints
Только 710 с product ID 1F61. Без прошивки, питания и звуковых эффектов. Изменения только по явному нажатию. Неофициальный клиент; протокол может зависеть от прошивки.

## Evidence on Hand
APK 3.1.4 с проверенной подписью Harman; BLE-чтение реальной 710; открытое описание PartyPair. Подробности в research/ и .agent/wiki/.
