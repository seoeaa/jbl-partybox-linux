# PartyBox 710 for Linux

**Неофициальный нативный GTK4/libadwaita-клиент JBL PartyBox 710.** Подсветка, RGB, громкость и Bass Boost по Bluetooth LE, плюс выбор колонки для системного звука через A2DP/PipeWire.

Не связан с JBL/Harman и не является их официальным продуктом. JBL и PartyBox — товарные знаки их владельцев. Иконка создана отдельно, без официального логотипа.

## Установка

Проверено на **Ubuntu 24.04**, Python 3.12, GTK 4.14, libadwaita 1.5 и PartyBox 710 с прошивкой **1.40.0**. Нужны Linux Bluetooth, BlueZ, PipeWire/WirePlumber и `pactl`/`busctl`.

Зависимости Ubuntu/Debian (если их ещё нет):

```bash
sudo apt install python3-gi gir1.2-gtk-4.0 gir1.2-adw-1 libadwaita-1-0 bluez pipewire-pulse wireplumber libspa-0.2-bluetooth
```

Установка без root, pip и виртуального окружения:

```bash
git clone https://github.com/seoeaa/jbl-partybox-linux.git
cd jbl-partybox-linux
./install.sh
```

Открой **PartyBox 710** в меню приложений. Либо:

```bash
~/.local/bin/partybox710
```

Программа устанавливается в `~/.local/share/jbl-partybox-linux`, launcher — `~/.local/bin/partybox710`. Повторный запуск установщика обновляет только файлы программы. Для запуска из исходников: `./run.sh`.

### Подключение

1. Включи колонку и Bluetooth на компьютере; при необходимости сопряги их в настройках Ubuntu.
2. Открой программу. Адрес сопряжённой колонки с исходным именем JBL PartyBox 710 определяется автоматически. Для переименованной колонки укажи её MAC вручную.
3. Управление BLE подключится и прочитает настройки. Закрой JBL PartyBox на телефоне, если оно заняло канал.
4. Чтобы Linux воспроизводил музыку через колонку, нажми **«Выводить звук через колонку»**. Эта кнопка подключает A2DP, выбирает выход по умолчанию и переносит текущие аудиопотоки. При переключении громкость ограничивается сверху 20%; более низкая громкость не повышается. Кнопка также снимает mute с выбранного выхода.

**BLE-подключение для настроек и A2DP-подключение для музыки — разные вещи.** Статус Bluetooth «подключено» сам по себе не означает, что PipeWire создал аудиовыход. Кнопка «Проверить вывод звука» только читает состояние и ничего не переключает.

## Возможности

- Современный нативный интерфейс, системная светлая/тёмная тема и прокрутка.
- Световое шоу: выключено, Rock, Flow, Ripple, Cross, Flash.
- RGB-цвет, автоцвет, отдельные кольца динамиков, боковой свет и полосы.
- Громкость 0–32 и Bass Boost 0/1/2.
- Отдельный блок системного аудиовыхода Linux.
- Версия прошивки, диагностика фактических ответов.
- CLI только для чтения состояния:

```bash
./run.sh --read-state
./run.sh --address AA:BB:CC:DD:EE:FF --read-state
```

Настройки обновляются при подключении, после команд и кнопкой обновления, а не непрерывным мониторингом. После изменения настройки на физической колонке или в другом приложении нажми обновление.

## Безопасное поведение

При запуске выполняются только чтение аудиостатуса и чтение BLE-состояния. Никакого автоматического переключения аудиовыхода или записи настроек.

- Ползунок, выбор режима и цвета не отправляют команду до нажатия **Применить**.
- Переключатели световых элементов отправляют команду только при действии пользователя.
- Повышение громкости выше16/32 и включение Flash требуют подтверждения.
- Успех записи показывается только после ACK колонки и повторного чтения значения.
- Потерянная команда не повторяется автоматически: она могла дойти до устройства, даже если ответ потерян.
- Закрытие управления закрывает только собственный ATT-сокет, не BlueZ-аудиосоединение.

Не используется обновление прошивки, питание, TWS или DJ-звуки. Одновременно управляй одной колонкой одним экземпляром клиента.

## Как устроено

| Модуль | Назначение |
|---|---|
| `partybox/transport.py` | Отдельный Linux L2CAP/ATT-сокет, discovery GATT, входящий обмен MTU, уведомления |
| `partybox/protocol.py` | Кадры JBL, объединение TLV-ответов, проверки аргументов, ACK/readback |
| `partybox/audio.py` | Чтение PipeWire и явный выбор A2DP-аудиовыхода |
| `partybox/gui.py` | GTK4/libadwaita, один рабочий поток для I/O, обновление UI в main thread |
| `partybox/__main__.py` | Запуск GUI/CLI и поиск сопряжённой710 |

Runtime: стандартная библиотека Python и системный PyGObject. У710 уведомления RX приходят без CCCD-дескриптора подписки, поэтому используется отдельный ATT-сокет. Сервис `65786365-6c70-6f69-6e74-2e636f6d0000`, запись0002, уведомления0001; handles обнаруживаются, а не зашиты в код. Поддержка модели ограничена product ID1F61.

## Проверка и ограничения

Фактически проверено на своей710, firmware1.40.0:

- Чтение устройства, света, плеера и баса.
- ACK/readback записи громкости, баса, режима и колец с сохранением исходных значений.
- Реальное изменение RGB и восстановление цвета/авторежима.
- Восстановление A2DP-аудиовыхода, выборdefault и перенос активного браузерного потока; статус PipeWire RUNNING.
- GTK-интерфейс на760×760 и640×600, read-only проверка кнопки аудиостатуса; защита от вызова записи при программном обновлении Gtk.Switch.
- Синтаксис/компиляция Python и shell-проверки. Новые unit/integration/E2E-тестовые файлы не создавались.

Другие модели, прошивки, Linux-дистрибутивы и комбинации Bluetooth-адаптеров не проверены. Протокол может измениться после обновления firmware. EQ, TWS, karaoke/DJ, firmware update, deb/AppImage и Flatpak не реализованы. Физическую слышимость звука подтверждает пользователь; программная проверка показывает маршрутизацию аудиопотоков.
